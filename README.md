# Сайт-визитка с интерактивными элементами

Учебный проект, демонстрирующий навыки работы с нативным JavaScript, DOM и сторонними API.

## 🛠 Технологии
* HTML5, CSS3 (Flexbox, Grid, адаптивность)
* JavaScript 
* Интеграция с API DaData
* Работа с DOM 
* LocalStorage (сохранение данных на стороне клиента)

## ⚙️ Функционал
* Адаптивная верстка (сайт подстраивается под мобильные устройства).
* Всплывающее окно чата поддержки.
* Динамическое появление Яндекс.Карты при выборе адреса из подсказок DaData.
* Форма редактирования данных компании (изменение ссылки на сайт и телефона).
* Панель авторизации (регистрация и вход) с сохранением логина и пароля в `localStorage`.

## 🚀 Как запустить
Проект не требует сборки. Достаточно скачать репозиторий и открыть файл `index.html` в любом браузере.
